# 迹忆 V1.0 PRD（开发基线）

## 产品目标

验证用户是否愿意：

1. 把容易忘记的信息交给系统。
2. 在之后忘记时主动查询。
3. 相信系统返回的答案和证据。

V1 北极星指标：**成功找回的记忆数**。

## V1 核心闭环

```text
采集
  ↓
结构化
  ↓
保存证据
  ↓
查询
  ↓
命中证据
  ↓
给出可信答案
```

## 查询红线

### NO EVIDENCE -> NO MEMORY

没有可验证数据时，不允许大模型生成确定性个人事实。

### 可信等级

- `confirmed`：用户主动确认或高置信主动记录
- `evidence`：存在系统证据，但不是用户直接确认
- `inference`：只允许以“可能”表述
- `unknown`：没有足够证据

V1 查询接口当前只正式输出前三者中的 `confirmed/evidence` 与 `unknown`，暂不将 AI 推断作为个人事实。

## 物品位置

位置历史不得覆盖。

例如：

```text
9/1  护照 -> 卧室床头柜      STALE
9/15 护照 -> 书房左柜第二层  CURRENT
```

查询必须优先最后一条 `CURRENT`。

用户点击“已经不在那里”后，将 `CURRENT` 改为 `STALE`，此后系统不得继续把它当成当前位置回答。

## 隐私暂停

暂停自动记忆不等于关闭整个 APP。

暂停期间：

- 自动位置点拒绝入库
- 后续自动照片扫描不得执行
- 后续自动事件生成不得执行
- 用户主动“记一下”仍然允许

这是产品必须长期遵守的语义。
