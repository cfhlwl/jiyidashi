# 迹忆 V1.0 PRD（开发基线）

## 产品目标

迹忆首先是个人 / 家庭长期记忆产品，不是 AI 技术演示。

核心目标：

1. 用户完成授权后，在系统允许范围内尽可能自动记录真实生活，降低“必须想起来打开 App 才能记录”的负担。
2. 用户仍可主动补充文字、语音、照片和纠错，主动记录拥有更高事实权威。
3. 在之后需要时，通过结构化检索与可信证据快速找回过去。
4. 对记录覆盖、不确定性和空档保持诚实，不把 AI 推断包装成真实经历。

V1 北极星指标：**成功找回的记忆数**。

## V1 核心闭环

```text
自动记录 / 主动记录
  ↓
结构化
  ↓
保存可信证据
  ↓
查询
  ↓
结构化检索优先
  ↓
必要时 AI 辅助整理
  ↓
给出可信答案
```

AI 只用于辅助搜索、整理、总结和表达；结构化事实 / Evidence 才是个人事实来源。没有足够证据时，不生成确定性的个人事实。

自动记录不是“永远在线”的承诺。记录效果受系统权限、后台策略、网络和设备状态影响；用户可通过 Recording Health 查看最近记录、同步状态和已知空档。

当前核心自动记录能力已实现，但正式 Android/iOS 长期真机可靠性认证仍处于稳定化后的待验收状态，不得表述为已经通过完整 24h/72h 长期认证。

## 查询红线

### NO EVIDENCE -> NO MEMORY

没有可验证数据时，不允许大模型生成确定性个人事实。

### 可信等级

- `confirmed`：用户主动确认或高置信主动记录
- `evidence`：存在系统证据，但不是用户直接确认
- `inference`：只允许以“可能”表述
- `unknown`：没有足够证据

V1 查询接口当前只正式输出前三者中的 `confirmed/evidence` 与 `unknown`，暂不将 AI 推断作为个人事实。

## 物品位置

位置历史不得覆盖。

例如：

```text
9/1  护照 -> 卧室床头柜      STALE
9/15 护照 -> 书房左柜第二层  CURRENT
```

查询必须优先最后一条 `CURRENT`。

用户点击“已经不在那里”后，将 `CURRENT` 改为 `STALE`，此后系统不得继续把它当成当前位置回答。

## 隐私暂停

暂停自动记忆不等于关闭整个 APP。

暂停期间：

- 自动位置点拒绝入库
- 后续自动照片扫描不得执行
- 后续自动事件生成不得执行
- 用户主动“记一下”仍然允许

这是产品必须长期遵守的语义。
